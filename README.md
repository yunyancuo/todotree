# TodoTree

> 桌面便签式待办管理工具 — 暗金透明窗口，锁定吸附桌面，四分区 + 定时流转 + 无限层级子任务。

## 功能

### 四分区任务管理
| 分区 | 标记 | 说明 |
|------|------|------|
| 待完成 | `- [ ]` | 进行中的任务 |
| 已完成 | `- [x]` | 已完成，60 秒后自动移入 |
| 目标 | `- [>]` | 长期目标 |
| 放弃 | `- [~]` | 放弃的任务，60 秒后自动移入 |

### 状态循环
点击任务左侧的状态点，在所有任务类型中循环切换：
1. **待办** — 空白
2. **完成** ✓ — 绿色勾 + 划线，60 秒后自动移入「已完成」分区
3. **加急** ! — 红色醒目文字 + 置顶
4. **放弃** ✗ — 灰色划线，60 秒后自动移入「放弃」分区

### DDL 截止日期
添加任务时可设置截止日期，过期日期显示红色警告。

### 层级任务
- 添加任务时可选择父任务，创建无限层级子任务
- 每个父任务可展开/折叠子任务列表
- 分区内支持全局展开/折叠

### 清除与撤回
- 每个分区有独立「清除」按钮，一键清空该分区
- 点击 × 或右键菜单删除单个任务
- **↩ 撤回按钮** — 支持撤销最近 20 次操作

### 桌面吸附
- 默认锁定在桌面，不在任务栏显示
- 点击 📌 解锁后，标题栏可拖动，拖到屏幕边缘自动吸附对齐
- 解锁后四角可拉伸调整窗口大小

## 项目结构

```
todotree-app/
├── main.js                 # Electron 主进程（文件 IO、窗口管理）
├── preload.js              # IPC 桥接（安全通信）
├── renderer/
│   ├── index.html          # UI 界面
│   ├── style.css           # Catppuccin 暗色主题
│   └── app.js              # 核心逻辑（解析/渲染/定时/状态机）
├── TODOTREE-template.md    # 空白模板文件
├── start.bat               # Windows 双击启动
├── package.json
└── README.md
```

## 数据格式

数据以 Markdown 文件存储（默认 `~/Desktop/TODOTREE.md`）：

```markdown
# TodoTree

## 待完成
- [ ] 普通待办
- [!] 加急任务 | ddl:2026-08-10
  - [ ] 子任务

## 已完成
- [x] 已完成任务

## 目标
- [>] 长期目标 | ddl:2026-12-31

## 放弃
- [~] 废弃任务
```

## 安装与运行

```bash
# 克隆项目
git clone https://github.com/your-username/todotree.git
cd todotree-app

# 安装依赖
npm install

# 启动
npm start

# 或 Windows 上双击
start.bat
```

## 技术栈

- [Electron](https://www.electronjs.org/) — 桌面应用框架
- Vanilla JavaScript — 无框架依赖
- Node.js fs API — 文件读写
- Markdown — 数据持久化格式
